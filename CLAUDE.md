# Agency Operational Rules

- **Target Audience:** High-value creators (YouTube, Newsletters) looking to sell $5,000–$15,000 packages (Masterminds, 1-on-1 Coaching, Done-With-You Consulting).
- **Coding Style:** Clean, production-ready Next.js 14+ (App Router), TailwindCSS, TypeScript. Always use modular, accessible UI design patterns.
- **Copywriting Style:** Direct-response, high-empathy, zero fluff. Write for high-intent, busy buyers. No cheesy "hype" or fake scarcity. Focus on clear ROI, case studies, and systemic transformation.
- **Technical Rules:** Validate all API data payloads strictly. Ensure lead data matches the standard schema (Name, Email, Social Link, Revenue/Budget Tier, Core Bottleneck).

See `agency_blueprint.md` for the full system architecture and workflow matrix this workspace is built around.
