# /brand code
`code/brand.py` is the style library (title, stack, caption, pill, paper image, grade, speaker framing).
`code/m80.py` (10-out-of-10 habits) and `code/m82.py` (Dostoevsky) are two finished edits built on it; copy one and change the PLAN block (word-anchored windows).
`code/mkcut.py`, `selcut.py`, `tighten.py` cut raw takes by word timings. `code/gi9.py` fetches Wikimedia Commons candidates.
Fonts: `assets/InstrumentSerif-*.ttf` (OFL). Paths inside the scripts point at an old scratchpad (`SC=...`): update them. Needs ffmpeg, numpy, opencv, scipy, pillow, faster-whisper.
