- The newest inspo wins when two conflict (`too_smart` over `grow50k` over the earlier overlay/hook looks).
- Fonts: never copy a creator's font files; match the look with the closest open font (Instrument Serif, Inter, Poppins).
- When the user gives a new inspo: add it to `inspiration.json`, save contact sheets to `thumbs/`, add a 'copy' line, then update the matching skill.
- Uploads that are not on Drive disappear with the session: ask the user for a Drive link and record the id.
